Where it started: Mindustry logic.

I started programming inside a game, on my phone.

Mindustry has a logic processor you program in a language called mlog. I learned it on my phone, bit by bit, because I like to program, and my skills kept sharpening.

Then I moved on to Mindustry mods written in JavaScript, which led me to web development, Java and semantic HTML.

One of my creations is a schematic that monitors launch pad items. Its display draws a realtime graph of the item flow. It comes from my save data of playing Mindustry v6 in 2025.

The save data is ready to import into your Mindustry. Give it a try.
